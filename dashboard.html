샘플 데이터

검색어별 자체 콘텐츠 최고 순위

최근 수집일 기준, 각 검색영역 상위 N개 결과 중 직방 콘텐츠의 최고 순위. 괄호는 전일 대비 변동. 행을 누르면 해당 검색어로 전환돼요.

검색 관심도 (검색어 트렌드)

네이버 통합검색 검색량의 상대값 (기간 내 최대 = 100). 주제어 그룹끼리 비교할 수 있어요.

최고 순위 추이 ·

검색영역별 직방 자체 콘텐츠 최고 순위 (위로 갈수록 좋음). 끊긴 구간은 상위 N개 안에 없던 날이에요.

검색 점유율 추이 ·

상위 N개 결과 중 직방 자체 콘텐츠, 직방 언급, 경쟁사 언급 비율.

최신 검색 결과 ·

최근 수집일의 정확도순 결과. 주황색 행이 직방 자체 콘텐츠예요.

최근 변동 알림

핵심 검색어의 상위 10위 진입·이탈, 최고 순위 큰 변동.

    신규 콘텐츠 (최근 7일)

    블로그·뉴스 각 최신순 100개 중 최근 7일 안에 발행된 글 수의 합. 막대 안의 주황색이 직방 자체 콘텐츠예요.
    지표 해석 시 주의
    · 검색 API는 영역별(블로그/카페/뉴스/웹문서) 결과를 주며, 통합검색 화면 배치(AI 브리핑, 광고, 클립, 스마트블록)와 개인화 결과는 반영하지 않아요.
    · 실제 노출수·클릭수는 네이버 서치어드바이저(str.zigbang.com), 유입·전환은 GA/UTM으로 보완해 주세요.
    · 검색어 트렌드 값은 요청 단위의 상대값이라 날마다 다시 계산돼요.
